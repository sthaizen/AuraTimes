# AuraTimes– Dynamic Watch Reselling Website

Developed a dynamic e-commerce website for watch reselling with secure login, encryption, session management, and role-based access for users and admins. Built using Java, JSP, and Servlets following the MVC architecture. Implemented full CRUD operations for products, carts, orders, and user profiles.
